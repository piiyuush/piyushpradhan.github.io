Engineering details

Development & Deployment

+

Single-file Node.js 22 backend (~4800 lines, zero framework, zero DB) + vanilla HTML/CSS/JS frontend. Docker → Kubernetes via Helm → ArgoCD auto-sync on merge; every push redeploys itself.

Performance & Reliability

+

HTTPS keepalive pool, exponential backoff on 429/5xx, tiered Map caches (5 min–24 hr TTLs), startup prewarming, /healthz probes. Minutes of manual stitching → sub-second loads.

Integrations

+

Jira REST v3 + GraphQL, Aha! v1, Confluence, and a dedicated GitHub App via @octokit/auth-app — correlating tickets ↔ PRs ↔ reviewers in one view.

Security & Ops

+

AWS Secrets Manager → ExternalSecret → CSI volume mount in prod. GPG-signed commits, detect-secrets pre-commit, Jira-linked PRs, zero hardcoded tokens. On-call owner end-to-end.

AI Usage

+

Claude Code drove scaffolding, refactors, and integrations — GitHub App auth, Helm/values edits, ExternalSecret templates, GraphQL, retry/cache logic. Every line human-reviewed, GPG-signed, PR-gated.
